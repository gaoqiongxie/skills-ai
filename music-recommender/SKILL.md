# 🎵 音乐推荐与歌单生成

根据你的情绪、场景、天气或活动，推荐最合适的音乐，生成有主题、有编排的歌单。

## 🛠️ 歌单生成逻辑

### 一首好歌单的编排原则

```
歌单时长：建议 30-60 分钟（10-15 首歌）

编排结构：
├── 开场（1-2首）：设定基调，建立情绪
├── 铺垫（2-3首）：情绪升温或深入
├── 高潮（3-4首）：核心表达，情绪顶点
├── 回落（2-3首）：逐渐平复，留有余韵
└── 收尾（1首）：点睛之笔，让人想重来

节奏曲线：
慢 → 中 → 快 → 中 → 慢（V型）
或
中 → 慢 → 慢 → 中 → 快（情绪释放型）
```

### 曲目信息模板

每首歌提供：
- 歌名 - 歌手
- 推荐原因（为什么适合这个场景）
- 风格标签
- 情绪关键词
- 平台链接占位（网易云/QQ音乐/Spotify/Apple Music）

## 🎨 流派速查

| 流派 | 一句话特征 | 代表艺人 |
|------|-----------|---------|
| **流行（Pop）** | 旋律抓耳，结构工整，大众接受度高 | Taylor Swift, 周杰伦 |
| **摇滚（Rock）** | 电吉他驱动，反叛精神，现场感强 | 五月天, Queen |
| **嘻哈（Hip-Hop）** | 说唱为主，节拍为王，街头文化 | Eminem, 马思唯 |
| **R&B** | 灵魂乐底子，转音多，情感细腻 | 陶喆, The Weeknd |
| **电子（Electronic）** | 合成器音色，舞曲结构，制作先行 | 尚雯婕, Daft Punk |
| **爵士（Jazz）** | 即兴演奏，复杂和弦，摇摆感 | 王若琳, Miles Davis |
| **民谣（Folk）** | 原声乐器，叙事歌词，真诚感 | 赵雷, Bob Dylan |
| **金属（Metal）** | 重型失真，快速 riff，极端人声 | 夜叉, Metallica |
| **古典（Classical）** | 管弦乐编制，严谨结构，无即兴 | 郎朗, 贝多芬 |
| **City Pop** | 80s 日本都市感，合成器贝斯，夏日 | 山下达郎, 杏里 |
| **国风** | 中式乐器+现代编曲，古诗词意象 | 银临, 李玉刚 |
