## 📝 量表 1：PHQ-9 抑郁症状自评

> **Patient Health Questionnaire-9**
> 来源：美国APA推荐的标准化筛查工具，广泛用于初级医疗和心理咨询

### 评估说明

在过去 **两周内**，以下问题困扰你的频率如何？

### 评分标准

| 分值 | 频率 |
|------|------|
| 0 | 完全没有 |
| 1 | 好几天 |
| 2 | 一半以上的天数 |
| 3 | 几乎每天 |

### 题目

**1. 做事时提不起劲或没有兴趣**
- 0 完全没有 / 1 好几天 / 2 一半以上 / 3 几乎每天

**2. 感到心情低落、沮丧或绝望**
- 0 完全没有 / 1 好几天 / 2 一半以上 / 3 几乎每天

**3. 入睡困难、睡不安稳或睡眠过多**
- 0 完全没有 / 1 好几天 / 2 一半以上 / 3 几乎每天

**4. 感觉疲倦或没有活力**
- 0 完全没有 / 1 好几天 / 2 一半以上 / 3 几乎每天

**5. 食欲不振或吃太多**
- 0 完全没有 / 1 好几天 / 2 一半以上 / 3 几乎每天

**6. 觉得自己很糟——或觉得自己很失败，或让自己或家人失望**
- 0 完全没有 / 1 好几天 / 2 一半以上 / 3 几乎每天

**7. 对事物专注有困难，例如阅读报纸或看电视时**
- 0 完全没有 / 1 好几天 / 2 一半以上 / 3 几乎每天

**8. 动作或说话速度缓慢到别人已经察觉？或正好相反——烦躁或坐立不安、动来动去的情况更胜于平常**
- 0 完全没有 / 1 好几天 / 2 一半以上 / 3 几乎每天

**9. 有不如死掉或用某种方式伤害自己的念头**
- 0 完全没有 / 1 好几天 / 2 一半以上 / 3 几乎每天

### 计分与解读

**总分 = 9题得分之和（0-27分）**

| 分数区间 | 严重程度 | 建议 |
|----------|---------|------|
| **0-4分** | 无或极轻微 | 情绪状态良好，继续保持健康生活方式 |
| **5-9分** | 轻度 | 关注情绪变化，尝试自我调节（运动、社交、作息调整） |
| **10-14分** | 中度 | 建议预约心理咨询师或精神科医生评估，不要独自承受 |
| **15-19分** | 中重度 | 建议尽快寻求专业帮助，可能需要心理治疗或药物干预 |
| **20-27分** | 重度 | **请立即联系专业医疗机构或心理危机热线** |

### ⚠️ 第9题特别关注

如果第9题（自伤念头）得分 **≥1分**：
- 无论总分多少，都建议**立即与信任的人倾诉**
- 考虑预约心理咨询师或精神科医生
- 可以拨打心理援助热线倾诉
- **请把危险物品移出可及范围**

## 📝 量表 2：GAD-7 焦虑症状自评

> **Generalized Anxiety Disorder-7**
> 来源：广泛性焦虑障碍的标准化筛查工具

### 评估说明

在过去 **两周内**，你被以下问题困扰的频率如何？

### 评分标准（同 PHQ-9）

| 分值 | 频率 |
|------|------|
| 0 | 完全没有 |
| 1 | 好几天 |
| 2 | 一半以上的天数 |
| 3 | 几乎每天 |

### 题目

**1. 感到紧张、焦虑或急切**
- 0 完全没有 / 1 好几天 / 2 一半以上 / 3 几乎每天

**2. 不能停止或控制担忧**
- 0 完全没有 / 1 好几天 / 2 一半以上 / 3 几乎每天

**3. 对各种事情担忧过多**
- 0 完全没有 / 1 好几天 / 2 一半以上 / 3 几乎每天

**4. 很难放松下来**
- 0 完全没有 / 1 好几天 / 2 一半以上 / 3 几乎每天

**5. 烦躁不安，坐立不宁**
- 0 完全没有 / 1 好几天 / 2 一半以上 / 3 几乎每天

**6. 变得容易烦恼或易怒**
- 0 完全没有 / 1 好几天 / 2 一半以上 / 3 几乎每天

**7. 感到好像有可怕的事要发生**
- 0 完全没有 / 1 好几天 / 2 一半以上 / 3 几乎每天

### 计分与解读

**总分 = 7题得分之和（0-21分）**

| 分数区间 | 严重程度 | 建议 |
|----------|---------|------|
| **0-4分** | 无或极轻微 | 焦虑水平正常 |
| **5-9分** | 轻度 | 尝试放松训练、正念呼吸、规律运动 |
| **10-14分** | 中度 | 建议寻求心理咨询，学习焦虑管理技巧 |
| **15-21分** | 重度 | 建议尽快就医，可能需要心理治疗或药物干预 |

## 📝 量表 3：PSS-10 压力知觉量表

> **Perceived Stress Scale-10**
> 来源：美国Cohen等编制，评估个体对生活中压力事件的感知程度

### 评估说明

在过去 **一个月内**，以下描述在多大程度上符合你的感受？

### 评分标准

| 分值 | 符合程度 |
|------|---------|
| 0 | 从不 |
| 1 | 几乎不 |
| 2 | 有时 |
| 3 |  fairly often（相当频繁） |
| 4 | very often（非常频繁） |

### 题目

**1. 因意外发生的事情而感到心烦意乱**
- 0 从不 / 1 几乎不 / 2 有时 / 3 相当频繁 / 4 非常频繁

**2. 感觉无法掌控生活中重要的事情**
- 0 从不 / 1 几乎不 / 2 有时 / 3 相当频繁 / 4 非常频繁

**3. 感到紧张和压力**
- 0 从不 / 1 几乎不 / 2 有时 / 3 相当频繁 / 4 非常频繁

**4. 成功处理了生活中的恼人问题**（反向计分：0→4, 1→3, 2→2, 3→1, 4→0）
- 0 从不 / 1 几乎不 / 2 有时 / 3 相当频繁 / 4 非常频繁

**5. 感到能应对必须做的事情**（反向计分）
- 0 从不 / 1 几乎不 / 2 有时 / 3 相当频繁 / 4 非常频繁

**6. 感到事情不顺心意**
- 0 从不 / 1 几乎不 / 2 有时 / 3 相当频繁 / 4 非常频繁

**7. 感到能控制个人生活中的愤怒情绪**（反向计分）
- 0 从不 / 1 几乎不 / 2 有时 / 3 相当频繁 / 4 非常频繁

**8. 感到问题堆积如山，无法逾越**
- 0 从不 / 1 几乎不 / 2 有时 / 3 相当频繁 / 4 非常频繁

**9. 感到事情都在掌控之中**（反向计分）
- 0 从不 / 1 几乎不 / 2 有时 / 3 相当频繁 / 4 非常频繁

**10. 感到因无法控制的事而愤怒**
- 0 从不 / 1 几乎不 / 2 有时 / 3 相当频繁 / 4 非常频繁

### 计分与解读

**总分 = 10题得分之和（注意第4、5、7、9题为反向计分，总分0-40分）**

| 分数区间 | 压力水平 | 建议 |
|----------|---------|------|
| **0-13分** | 低压力 | 压力管理良好，继续保持 |
| **14-26分** | 中等压力 | 建议引入压力管理策略（运动、社交、休息） |
| **27-40分** | 高压力 | 建议寻求专业支持，检视生活/工作中的压力源 |

## 📝 量表 4：MBI-GS 简易职业倦怠自评

> **Maslach Burnout Inventory - General Survey（简易版）**
> 来源：职业倦怠研究的黄金标准量表简化版

### 评估说明

用 **1-5分** 评估以下描述符合你的程度。

### 评分标准

| 分值 | 符合程度 |
|------|---------|
| 1 | 完全不符合 |
| 2 | 不太符合 |
| 3 | 一般 |
| 4 | 比较符合 |
| 5 | 完全符合 |

### 题目

** exhaustion（耗竭）维度 **

**1. 工作让我感觉身心俱疲**
- 1 完全不符合 / 2 不太符合 / 3 一般 / 4 比较符合 / 5 完全符合

**2. 下班时我感觉累坏了**
- 1 完全不符合 / 2 不太符合 / 3 一般 / 4 比较符合 / 5 完全符合

**3. 早晨一起床，我就想到工作就感到累**
- 1 完全不符合 / 2 不太符合 / 3 一般 / 4 比较符合 / 5 完全符合

** cynicism（去人格化/疏离）维度 **

**4. 我对工作越来越没有热情**
- 1 完全不符合 / 2 不太符合 / 3 一般 / 4 比较符合 / 5 完全符合

**5. 我开始怀疑工作的意义**
- 1 完全不符合 / 2 不太符合 / 3 一般 / 4 比较符合 / 5 完全符合

**6. 我对工作越来越敷衍**
- 1 完全不符合 / 2 不太符合 / 3 一般 / 4 比较符合 / 5 完全符合

** professional efficacy（成就感降低）维度 **

**7. 我觉得自己能有效地解决工作中的问题**（反向计分：1→5, 2→4, 3→3, 4→2, 5→1）
- 1 完全不符合 / 2 不太符合 / 3 一般 / 4 比较符合 / 5 完全符合

**8. 我觉得自己的工作有价值**（反向计分）
- 1 完全不符合 / 2 不太符合 / 3 一般 / 4 比较符合 / 5 完全符合

**9. 我有信心完成工作任务**（反向计分）
- 1 完全不符合 / 2 不太符合 / 3 一般 / 4 比较符合 / 5 完全符合

### 计分与解读

**三个维度分别计算平均分（1-5分）**

| 维度 | 低（1-2分） | 中（2-3分） | 高（3-5分） |
|------|------------|------------|------------|
| **耗竭** | 精力充沛 | 偶尔疲惫 | 严重倦怠 |
| **疏离** | 热情投入 | 偶有冷漠 | 彻底疏离 |
| **成就感** | 成就感高 | 时有怀疑 | 成就感极低 |

### 综合判断

| 类型 | 表现 | 建议 |
|------|------|------|
| **积极型** | 耗竭低 + 疏离低 + 成就感高 | 状态良好 |
| **过度投入型** | 耗竭高 + 疏离低 + 成就感高 | 有激情但消耗大，注意边界 |
| **倦怠型** | 耗竭高 + 疏离高 + 成就感低 | 典型 burnout，建议休息 + 寻求支持 |
| **疏离型** | 耗竭低 + 疏离高 + 成就感低 | 工作无意义感，考虑转岗或调整 |
